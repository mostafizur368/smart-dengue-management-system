SMART DENGUE MANAGEMENT SYSTEM - FREE CHATBOT PACKAGE

Upload the CONTENTS of this folder to the ROOT of your GitHub repository.
Do not upload this folder as a nested folder.

Excluded intentionally:
- .env (not required for the free local chatbot)
- node_modules (install dependencies with npm install)

The active chatbot uses the browser-side Question Bank and Free Hybrid Search.
No OpenAI API key, Gemini API key, or paid AI service is required for the chatbot search.

Backend:
- Entry point: server.js
- Run: npm install
- Start: npm start

Website files:
- assets/css/style.css
- assets/images/dengue.png
- assets/js/doctors.js
- assets/js/dengue-questions.js
- assets/js/dengue-search.js
- assets/js/script.js

The legacy /api/chat endpoint is disabled and does not call a paid AI provider.
